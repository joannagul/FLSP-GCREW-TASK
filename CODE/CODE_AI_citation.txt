You can easily brighten and crisp up the aerial imagery without making it look artificial by overriding Cartopy's tile fetcher to apply a quick PIL (Pillow) brightness and contrast boost as the tiles load. Pillow is already bundled with matplotlib and cartopy, so you don't need to install anything.

Replace your esri_imagery = cimgt.GoogleTiles(...) block with this custom subclass:

Python
from PIL import ImageEnhance

class BrightEsriTiles(cimgt.GoogleTiles):
    def __init__(self, brightness=1.35, contrast=1.15):
        super().__init__(
            url='https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}'
        )
        self.brightness = brightness
        self.contrast = contrast

    def get_image(self, tile):
        img, extent, origin = super().get_image(tile)
        img = ImageEnhance.Brightness(img).enhance(self.brightness)
        img = ImageEnhance.Contrast(img).enhance(self.contrast)
        return img, extent, origin

esri_imagery = BrightEsriTiles(brightness=1.35, contrast=1.15)
brightness=1.35 lifts those dark marsh and shadow tones by 35% without blowing out the water.

contrast=1.15 keeps the creek channels separated from the marsh grass so it doesn't look washed out. (If it's still slightly dark on your screen, bump brightness to 1.45.)

For comparing two seasons (Summer vs. Winter) within each water type (SW, PW, GW), you are testing differences between two independent groups for each variable and water type combination.

Because environmental geochemistry data (radium activities, DIC, DOC, salinity) frequently has small sample sizes per group (especially in PW and GW) and can be skewed with outliers, the standard approach is a two-group comparison—either Mann-Whitney U (non-parametric, compares medians/distributions without assuming normality) or Welch's t-test (parametric, compares means without assuming equal variance).

from scipy import stats

# Variables available in GCREW
gcrew_vars = [
    'Salinity', 'Ra224_226', 'Ra224_dpm100L', 'Ra226_dpm100L',
    'DIC_umolL', 'DOC_umolL', 'TA_mmolkg'
]

results = []

for var in gcrew_vars:
    for stype in ['SW', 'PW', 'GW']:
        sub = data_gcrew[data_gcrew['Sample_Type'] == stype]
        
        # Split by season and drop missing values
        summer = sub[sub['Season'] == 'Summer'][var].dropna()
        winter = sub[sub['Season'] == 'Winter'][var].dropna()
        
        # Need at least 2 observations in each season to run a test
        if len(summer) >= 2 and len(winter) >= 2:
            u_stat, p_mwu = stats.mannwhitneyu(summer, winter, alternative='two-sided')
            t_stat, p_ttest = stats.ttest_ind(summer, winter, equal_var=False)
            
            results.append({
                'Variable': var,
                'Sample_Type': stype,
                'n_Summer': len(summer),
                'n_Winter': len(winter),
                'Median_Summer': round(summer.median(), 2),
                'Median_Winter': round(winter.median(), 2),
                'p_MannWhitney': round(p_mwu, 4),
                'p_Welch_t': round(p_ttest, 4),
                'Sig_raw (p<0.05)': 'Yes' if p_mwu < 0.05 else 'No'
            })
        else:
            results.append({
                'Variable': var,
                'Sample_Type': stype,
                'n_Summer': len(summer),
                'n_Winter': len(winter),
                'Median_Summer': round(summer.median(), 2) if len(summer) else None,
                'Median_Winter': round(winter.median(), 2) if len(winter) else None,
                'p_MannWhitney': None,
                'p_Welch_t': None,
                'Sig_raw (p<0.05)': 'Insufficient n'
            })

stats_df = pd.DataFrame(results)

# Optional: Benjamini-Hochberg FDR correction across all valid tests
valid_mask = stats_df['p_MannWhitney'].notna()
stats_df.loc[valid_mask, 'p_FDR_adj'] = stats.false_discovery_control(
    stats_df.loc[valid_mask, 'p_MannWhitney'], method='bh'

No—you never need a preliminary test to "earn permission" to use the median.

Here is the core rule in statistics:

The mean is the one that requires assumptions (symmetry, no extreme outliers, roughly normal distribution) to represent a "typical" sample accurately.

The median (the exact 50th percentile middle value) always works—whether your data is skewed, has extreme hotspots, or is a completely textbook bell curve. Even if a column happens to be perfectly symmetric, the mean and the median are nearly identical anyway.

    valid_groups = [g for g in groups if len(g) >= 2]
    
    if len(valid_groups) >= 2:
        kw_stat, p_kw = stats.kruskal(*valid_groups)
        lev_stat, p_lev = stats.levene(*valid_groups, center='median')

            'Medians (n)': med_str,

        })

    g24 = sw_task[sw_task['Season'] == 'Spring 2024'][var].dropna()

Why We Used Two Different Tests
Think of Mann-Whitney U and Kruskal-Wallis as the exact same test, just scaled for how many groups you are comparing:

Mann-Whitney U is strictly for comparing 2 groups (like Spring 2024 vs. Spring 2025).

Kruskal-Wallis is the exact same non-parametric test extended to 3 or more groups (like Fall 2023 vs. Fall 2024 vs. Fall 2026). You can't run Mann-Whitney U on three years at once because it only accepts two inputs, so Kruskal-Wallis handles all three Fall campaigns simultaneously.

Both tests check whether the medians differ across years, and median-centered Levene's test works on both 2 groups and 3+ groups to check whether the spread/variability changed across years.

def get_cld_letters(campaigns, sig_pairs_set):
    """Assigns standard compact letter display (a, b, c...) from non-significant pairs."""
    # Sort campaigns by their order so 'a' starts with the earliest campaign
    n = len(campaigns)
    # Build sets of mutually non-significant campaigns (cliques)
    cliques = []
    for i in range(n):
        c_i = campaigns[i]
        placed = False
        for clq in cliques:
            if all((min(c_i, c_j), max(c_i, c_j)) not in sig_pairs_set for c_j in clq):
                clq.append(c_i)
                placed = True
        if not placed:
            cliques.append([c_i])
    
    # Remove redundant subsets
    maximal_cliques = []
    for clq in cliques:
        s_clq = set(clq)
        if not any(s_clq < set(other) for other in cliques):
            if clq not in maximal_cliques:
                maximal_cliques.append(clq)
                
    letters = 'abcdefghijklmnopqrstuvwxyz'
    letter_map = {c: '' for c in campaigns}
    for idx, clq in enumerate(maximal_cliques):
        for c in clq:
            letter_map[c] += letters[idx]
    return letter_map
