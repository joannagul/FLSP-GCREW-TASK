There are three specific reasons that code broke and popped up as a blank/massive box:

Extent Order Was Flipped: set_extent expects [west, east, south, north]. You had [-75.5, -77.5, ...] which flips west and east, making the plot turn inside out! It must be [-77.5, -75.5, ...].

Deprecation Warnings: Cartopy 0.26 updated its gridliner tools. LONGITUDE_FORMATTER is deprecated, and newer Cartopy versions format gridlines automatically without needing those old imports.

Missing Data Plotting & DPI: dpi=300 on a (10,8) figure makes it render huge on standard screens. Lowering to dpi=150 makes it fit your screen nicely, and we need to add ax.scatter() to actually draw your points on top of the map using transform=ccrs.PlateCarree().

Those are two minor warnings (not code-breaking errors) triggered by Python string escape characters and Seaborn's newer syntax update.

1. SyntaxWarning: invalid escape sequence '\m'
In Python, standard strings treat \m as a backslash escape attempt (like \n for a new line). Because \mu starts with \m, Python flags it. The fix is placing an r before the string to make it a raw string (e.g., r'DIC ($\mu$mol L$^{-1}$)').

2. FutureWarning: Passing palette without assigning hue
In newer versions of Seaborn, assigning a palette directly to x requires explicitly passing hue='Sample_Type' and setting legend=False.
